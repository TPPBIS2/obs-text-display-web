# OBS Text Display

เว็บแอปสำหรับเลือกห้องจาก Excel แล้วส่งชื่อห้อง นักเรียน และครูที่ปรึกษาไปยัง OBS Studio ผ่าน OBS WebSocket 5

## ใช้ Text Sources ใน OBS

สร้าง Text Sources โดยใช้ชื่อให้ตรงทุกตัว แอปจะสร้าง `text_room_rank` ให้อัตโนมัติในฉาก OBS ปัจจุบัน หากยังไม่มี โดยใช้ชนิดเดียวกับ Source `text_room`:

| ข้อมูล | ชื่อ Source |
| --- | --- |
| อันดับที่ | `text_room_rank` |
| ห้อง | `text_room` |
| นักเรียนคนที่ 1 | `text_student_1` |
| นักเรียนคนที่ 2 | `text_student_2` |
| ครูที่ปรึกษาคนที่ 1–3 | `text_teacher_1`, `text_teacher_2`, `text_teacher_3` |

กรอกอันดับของห้องที่เลือกในส่วนตัวอย่างข้อมูลก่อนส่งไป OBS ค่าที่กรอกจะแยกเก็บตามห้อง และส่งไปยัง Text Source `text_room_rank` โดยไม่รวมกับชื่อห้องหรือนักเรียน

## รูปแบบ Excel

- ชีตรายชื่อนักเรียนต้องมีห้อง เช่น `ม.1/2` และชื่ออยู่ในเซลล์ก่อนห้อง (เลขที่นักเรียนจะถูกข้าม)
- ชีตครูที่ปรึกษาควรมี `ครู` ในชื่อชีต หรือมีหัวตาราง `ครูที่ปรึกษา` ชื่อครูอยู่ในช่องแรกหลังห้อง
- รองรับรายชื่อครูหลายคนในช่องเดียว เช่น `1. ครู ก 2. ครู ข`
- ระบบจับคู่ชีตนักเรียนกับครูตามห้อง และรองรับเว้นวรรคในชื่อห้อง

## เว็บไซต์

GitHub Actions จะ build และเผยแพร่เว็บไซต์ไปยัง GitHub Pages เมื่อมี commit ใหม่บน branch `main`:

**https://tppbis2.github.io/obs-text-display-web/**

รอ workflow `Deploy to GitHub Pages` ในแท็บ **Actions** ให้สำเร็จก่อนเปิด URL การใช้หน้าเว็บที่ deploy แล้วต้องเปิด OBS บนเครื่องเดียวกันและกรอก Host เป็น `localhost` หาก OBS ปฏิเสธการเชื่อมต่อ ให้เพิ่ม origin ของเว็บไซต์ใน allowed origins ของ OBS
